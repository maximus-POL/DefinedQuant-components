# Financial Analysis

Deterministic comparisons of company financial statements and earnings from caller-supplied, explicitly aligned observations.

Components in this category never fetch filings, infer accounting definitions, translate
currencies, reconcile fiscal calendars, or repair missing observations. A comparison must declare
the metric, reporting currency, scale, period-alignment basis, and source label.

Results describe the supplied values and peer set. They do not establish accounting comparability,
investment merit, valuation, causal explanations, or future performance. Source filings and
company-specific events remain separate evidence that a caller may investigate after calculation.
